## I. Set Up Your Personal Repository

Follow these steps to initialize your own copy of the project:

### 1. Open the base repository

**Link:** [https://github.com/the-ak-foundation/ak-base-kit-stm32l151](https://github.com/the-ak-foundation/ak-base-kit-stm32l151)

### 2. Fork it to your account

Click the **Fork** button in the top-right corner to duplicate the project under your personal GitHub account.
Feel free to also press the **Star** button to support the maintainers.

<p align="center">
  <img width="1338" height="640" alt="repo-ak" src="../resources/images/guide-getting-started/getting_started_view_ak_foundation_repo.png" />
</p>

### 3. Configure the new fork

<p align="center">
  <img width="1338" height="640" alt="repo-ak" src="../resources/images/guide-getting-started/getting_started_create_fork.png" />
</p>

> **Note:**
> - Name the repository after **your game** (e.g. `alien_shooter`, `tank_battle`).
> - Write a short description of the game in the **Description** field.
> - Keep the repository **Public** so others can view your work and play the game.

Once the fork is ready, GitHub will redirect you to the new repository — this is the skeleton you will build your game on top of:

  <img width="1338" height="640" alt="repo-ak" src="../resources/images/guide-getting-started/getting_started_repo_after_fork.png" />

## II. Development Environment Setup

To compile the source code and flash firmware onto the kit, you need a working build environment on Ubuntu/Linux. Full installation instructions are available here:

**[AK Embedded Base Kit STM32L151 — Getting Started](https://epcb.vn/blogs/ak-embedded-software/ak-embedded-base-kit-stm32l151-getting-started)**

> **Required tools:** `arm-none-eabi-gcc`, `make`, `openocd` or `st-flash`, and VSCode with the C/C++ extension.

---

## III. Building Your First Game Feature

> **Note:** This is an embedded software project — always use the **Terminal on Ubuntu/Linux** to guarantee the build and flash steps run correctly.

### Step 1: Organize Your Project Directory

Inside your `Home` directory, create a top-level folder called **Workspace** to keep your source code and programming tools in one place.

<p align="center">
  <img width="1338" height="640" alt="repo-ak" src="../resources/images/guide-getting-started/getting_started_open_vscode_workspace.png" />
</p>

Inside `Workspace`, create two subdirectories:

| Directory | Purpose                                                                                               |
| --------- | ----------------------------------------------------------------------------------------------------- |
| `Sources` | Holds all of your game projects                                                                       |
| `Tools`   | Holds the compiler toolchain and flash utilities (see [Section II](#ii-development-environment-setup)) |

<p align="center">
  <img width="1338" height="640" alt="repo-ak" src="../resources/images/guide-getting-started/getting_started_create_sources_and_tools_folders.png" />
</p>

---

### Step 2: Download the Source Code

> **Note:** This step is only needed **once** when starting the project.

Open a **Terminal** inside the `Sources` directory and run the command below (replace the URL with your own repository link):

```bash
git clone https://github.com/<your-username>/<your-game-repo>.git
```

Then open the cloned folder in VSCode:

```bash
code <your-game-repo>/
```
